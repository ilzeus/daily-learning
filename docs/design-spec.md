# 设计规范 —— Daily Learning

> 版本：v0.2 | 最后更新：2026-06-22

---

## 配色方案

| Token 名称 | 色值 | 用途 |
|------------|------|------|
| `--color-primary` | `#122E8A` | 主色调（深海蓝），用于全局背景、按钮 |
| `--color-surface` | `#F5EFEA` | 卡片/输入区底色（米白） |
| `--color-text-primary` | `#122E8A` | 卡片/浅色区上的深色文字 |
| `--color-text-on-primary` | `#F5EFEA` | 深蓝背景上的浅色文字 |
| `--color-white` | `#FFFFFF` | 纯白（辅助） |

> **注意：** 全局背景是深蓝 `#122E8A`，卡片和输入框是米白 `#F5EFEA`，这是两个主色之间的关系，不是传统"主色+浅背景"的用法。

---

## 圆角规范

| Token 名称 | 值 | 用途 |
|------------|------|------|
| `--radius-default` | `16px` | **所有矩形元素的默认圆角** |

> **硬性规则：所有矩形（按钮、卡片、输入框、弹窗等）必须使用圆角 16px，禁止直角。**

---

## 字体规范

| Token 名称 | 值 | 用途 |
|------------|------|------|
| `--font-brand` | `'Caveat'` 或 `'Dancing Script'`, cursive | 顶部标题 "Daily Learning" |
| `--font-body` | 系统默认字体栈（`-apple-system, ...`） | 全局正文 |
| `--font-size-sm` | `14px` | 小号文字 / 提示 |
| `--font-size-md` | `16px` | 正文 |
| `--font-size-lg` | `20px` | 标题 |
| `--font-size-xl` | `28px` | 品牌标题 |
| `--font-weight-normal` | `400` | 正文 |
| `--font-weight-bold` | `700` | 标题/强调 |

> Google Fonts 通过 `<link>` 在 `index.html` 中引入。

## 组件规范

### 输入框
- 圆角 `16px`
- 背景 `#F5EFEA`（米白），文字 `#122E8A`（深蓝）
- 大尺寸，适合多行输入（textarea）
- placeholder 文字颜色：深蓝 + 透明度

### 按钮
- 圆角 `16px`
- 主按钮（生成笔记）：背景 `#F5EFEA`，文字 `#122E8A`（米白底深蓝字，与深蓝背景形成对比）
- 次按钮（保存到 Notion）：米白底 + 深蓝边框 + 深蓝文字
- disabled 状态：灰色背景，文字变淡

### 卡片（结果展示区）
- 圆角 `16px`
- 背景 `#F5EFEA`（米白）
- 文字 `#122E8A`（深蓝）
- 可滚动（`overflow-y: auto`）
- Markdown 内容由 marked.js 渲染

### 加载动画
- 进度条 + 像素鹰从左飞到右，循环播放
- 纯 CSS 动画或 JS 实现的简易帧动画

### 配置弹窗
- 圆角 `16px`
- 三个输入字段：DeepSeek API Key、Notion Token、Notion Database ID
- 保存 / 取消按钮
