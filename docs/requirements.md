# 功能需求文档 —— Daily Learning

> 版本：v0.2 | 最后更新：2026-06-22

---

## 项目概述

**项目名称：** Daily Learning

**一句话描述：** Windows 桌面端学习助手。用户输入想学习的概念，AI 自动生成结构化知识点和总结，支持一键保存到 Notion 知识库。

---

## 核心功能

### F1 — 学习内容输入

- 输入框位于标题下方，大尺寸圆角输入框
- placeholder 文字：`"输入你想学习的内容..."`
- 米白底色（`#F5EFEA`），深色文字

### F2 — AI 生成笔记

- 点击 **"生成笔记"** 按钮，调用 DeepSeek API
- 系统提示词：

  > 你是一位知识渊博的学习导师。根据用户输入的主题，生成相关核心知识点（数量由 AI 根据主题自主判断，不可遗漏核心内容），每个知识点附带简洁解释，最后给出一段总结。输出格式为 Markdown。

- **加载动画：** 生成期间显示像素鹰在进度条上从左飞到右，循环播放
- **生成完成：** 动画消失，结果区渲染 Markdown 内容（使用 marked.js）
- **生成失败：** 显示友好提示 `"生成失败，请检查网络或API配置后重试"`

### F3 — 保存到 Notion

- 生成内容后，**"保存到 Notion"** 按钮变为可用（未生成时置灰 disabled）
- 点击后调用 Notion API，在指定数据库中创建新页面：
  - **页面标题** = 用户输入的学习主题
  - **Content 内容** = AI 生成的完整 Markdown
  - **Date** = 当前日期
- 保存成功 / 失败有对应提示

### F4 — 首次启动配置

- 首次启动弹出配置窗口
- 配置项：
  - DeepSeek API Key
  - Notion Integration Token
  - Notion 数据库 ID
- 通过 **electron-store** 加密存储到本地
- 后续启动不再弹出，可在菜单中重新唤出修改

## 界面视觉规范

| 规范项 | 值 |
|--------|-----|
| 主背景色 | `#122E8A`（深海蓝） |
| 卡片/输入区底色 | `#F5EFEA`（米白） |
| 所有矩形元素圆角 | **16px**（硬性规则，禁止直角） |
| 窗口默认尺寸 | 480 × 680 px（允许用户拖拽调整） |
| Markdown 渲染 | marked.js |

- **顶部装饰：** 像素风格的鹰站在打开的书上（图片路径 `assets/eagle.png`），右侧或旁边用艺术字体（Google Fonts，如 Caveat 或 Dancing Script）显示 **"Daily Learning"**
- **按钮：** 统一圆角风格，与整体协调
- **结果展示区：** 卡片式布局，米白底，深蓝文字，可滚动
