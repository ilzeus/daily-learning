## 项目概述

**一句话描述：** Windows 桌面端学习助手。输入一个概念，一次拿到三种讲解风格，选一份归档到 Notion 或复制走。

**目标用户：** 每天学一个新概念、希望笔记落在自己库里的人（不是团队协作文档）。

## 核心功能

### F1 — 学习内容输入

- 顶部大尺寸圆角 textarea，placeholder：`输入你想学习的内容...`
- 判空：没输入就点生成 → toast「先输入想学习的内容」并把焦点送回输入框

### F2 — 一次生成三版

- 点「生成笔记」→ **同时**发出三个请求（学习版 / 专业版 / 笔记版），主按钮文案变「中止生成」，下方出现进度条
- 三版结果都留在内存里，切档只换视图，**不再发请求**
- 三套 system prompt 的差异化要求：
  - 学习版：大白话、生活类比、以连贯段落为主，结尾一行 `> 一句话记住：……`
  - 专业版：术语与机制、设计动机、与相近概念的取舍、常见坑，以论述段落为主
  - 笔记版：分层标题 + 短句列表 + 可对照的内容用 Markdown 表格，关键结论加粗
- 渲染：marked v4 → 本地转 HTML，排版随 `data-mode` 变（字号 / 行距 / 列表标记）
- **中止**：点「中止生成」→ 通过 requestId 掐掉还在飞的请求，已经回来的那一版保留可看
- **部分失败**：某一版没出来时，该档标签上留红点 + `title` 说明，切过去看到完整错误文案，同时 toast 点名「哪几版没生成出来」
- 错误文案必须说人话并给出下一步（「接口地址填错了」「网络连不上」「等得太久了」），不把 errno 甩在界面上

### F3 — 归档到 Notion（可选）

- 未生成时按钮 disabled
- 没配 Notion 时照样能点：打开配置窗 + 说明缺什么，而不是抛 API 错误
- 写入内容：
  - 页面标题 = `主题 · 版本名`
  - `Date` = 当天本地日期（不是 UTC），且仅当库里存在这个日期属性时才写
  - 正文 = 该版 Markdown 转成的 Notion 块（1–3 级标题 / 有序无序嵌套列表 / 待办 / 折叠 / 代码（带 language）/ 引用 / 表格（重复表头）/ 分割线 / 行内加粗·斜体·删除线·行内码；行内图片退化成可读链接，Notion 段落放不下 image 块）
- 数据库属性先探测再写：标题用库里实际的 title 属性（名字任意），库里没有 `Date` 就跳过，不报 400
- 块数超限时分批 append（单次 ≤100 顶层块、单段 rich_text ≤2000 字符）

### F4 — 配置

- 入口：标题栏齿轮按钮；首次启动且未配置时自动弹出，标题「首次配置」
- 字段：服务商（预设 6 家 + 自定义）、API Key、模型（可拉列表 / 手填）、接口地址（仅自定义时显示）、Notion Token（可选）、Notion 数据库 ID（可选）、本机笔记自动存盘开关、本机笔记目录（可直接填、可「自定义保存位置」、可「打开文件夹」；留空 = 用默认目录）
- 密钥字段留空 = 不改动已保存的值，placeholder 显示「已保存，留空表示不修改」
- 关闭控制：**没配齐时**（缺 Key / 模型 / 地址）取消、点遮罩、Esc 都不许关，并提示还差哪几项；配齐后可自由关闭
- 存储：JSON 文件放在应用数据目录；`apiKey` / `notionToken` 经 `safeStorage`（Windows DPAPI）加密为 `enc:v1:...` 后落盘
- 迁移：老版本字段名（`deepseekApiKey`）和明文密钥在启动时自动升级，用户不需要重填
- 读取异常要如实上报（文件损坏 / 换机器解不开 / 系统密钥库不可用），启动时用 toast 说清楚，不伪装成「还没配置」

### F5 — 本机笔记落盘

- 默认目录为 `<应用数据目录>/notes`，用户可在配置窗改成任意文件夹（「自定义保存位置」走系统目录选择器，也可以直接粘路径）
- 每版生成成功、**且开关打开时**立刻写一个 `.md` 到上面这个目录
- 文件名：`YYYY-MM-DD HH-mm-ss <版本名> <净化后的主题>.md`，时间用本地时区，主题里的 `\ / : * ? " < > |` 和控制字符换成空格、限长 40
- 写盘失败不影响已经生成好的笔记显示，但要 toast 说明「没能存到本机」及原因
- 配置窗里显示完整路径 + 「自定义保存位置」+「打开文件夹」
- 自动存盘可在配置窗里关掉（`autoSaveNotes`）：关掉后生成结果只在屏幕上，不写文件、也不创建目录；复制和存 Notion 不受影响
- 这个开关**默认是关的**（`autoSaveNotes` 缺失或不是 `true` 都按关处理）——写盘是副作用，不默认替用户往硬盘上东西
- 路径只接受完整路径（盘符开头或 UNC）；填了相对路径当场报错、配置窗不关，不写坏配置

### F6 — 复制 Markdown

- 结果区底部「复制 Markdown」按钮，复制**当前这一版**的原文
- 走主进程 `clipboard`（渲染进程没有 Node，浏览器 clipboard API 在窗口失焦时会静默失败）
- 成功 / 失败都有 toast

## 非功能需求

| 类别 | 要求 | 现状 |
|------|------|------|
| 进程隔离 | 渲染进程无 Node 能力，仅经白名单 IPC | ✅ `contextIsolation` + `preload.js` |
| CSP | 禁远程脚本、禁渲染进程发起网络 | ✅ `script-src 'self'`、`connect-src 'none'` |
| 密钥 | 不以明文跨进程、不明文落盘 | ✅ DPAPI + 只回布尔值 |
| 外链 | 不在应用内打开 | ✅ 拦截导航/弹窗，交系统浏览器 |
| 键盘 | 焦点可见、切档可用左右箭头/Home/End、Esc 关弹窗、F12 开控制台、Ctrl+Q 退出 | ✅ |
| 对比度 | 文字灰阶过 WCAG AA | ✅ muted 6.8:1 / faint 4.5:1 |
| 打包 | electron-builder → 便携版 + NSIS | ⚠️ 配置就绪，重构后未重新出包 |

## 界面视觉

见 [`docs/design-spec.md`](docs/design-spec.md)。要点：浅灰底 + 白色卡片 + 墨黑 pill 主按钮，彩色只用于语义状态（绿=成功/强调，红=错误），无 emoji、无像素鹰、无蓝色主题。

## 规划 → 现实的差异

| v0.2 规划 | 实际 |
|-----------|------|
| 只接 DeepSeek | 6 家预设 + 任意 OpenAI 兼容自定义地址 |
| 一种输出风格 | 三种风格，一次全出，可切档 |
| 像素鹰飞行加载动画 | 细进度条 + 文案，品牌图换成鹰徽标 |
| 深蓝 `#122E8A` + 米白 | Apple 灰阶 + 系统绿强调 |
| electron-store 存配置 | `fs` + JSON + DPAPI 加密（v1.0 内已替换） |
| Notion 必填 | 可选，另加本机落盘与复制两条退路 |
| 菜单栏「设置 → 配置」 | 去掉系统菜单，配置入口在标题栏 |
