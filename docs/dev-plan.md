## 还没做 / 没验证

- **安装包的实机运行**：v1.1.0 的两个 exe 已构建、已上传 Releases，但**没有双击跑过**（便携版会解包到临时目录、装到 `%LOCALAPPDATA%`，属于留痕动作）。已核对的是 asar 里的文件清单（`main.js` / `preload.js` / `scripts/` 9 个模块 / `styles` / 4 张 png，依赖只有 `marked`）与 `latest.yml` 的 SHA512；`Get-AuthenticodeSignature` 两个包都是 `NotSigned`。
- **真实接口端到端**：所有 API 相关的验证都是本地 mock 服务。真机上的 DeepSeek / Kimi / Notion 全流程取决于使用者自己的 Key，未验证。
- **`打开文件夹` 按钮的真·资源管理器**：探针仍然没真点（会弹窗口），但把 `shell.openPath` 打桩成 resolve 空串 / 英文原因两条路都跑过了——顺带发现并修掉了漏 `await` 导致这个按钮**永远报错**的 bug（见 devlog 2026-10-02）。
- **macOS / Linux**：完全没测。
- **多窗口 / 托盘 / 自动更新**：不在计划内。
