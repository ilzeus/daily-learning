## 测试与修复

### Bug 1：electron-store v8 导致 renderer.js 崩溃
- **现象**：打开应用后配置弹窗不显示，所有功能不可用
- **原因**：`electron-store` v8 需要主进程调用 `initRenderer()` 才能在工作进程使用，且依赖链复杂
- **修复**：移除 `electron-store`，改用 Node.js 内置 `fs` 模块 + IPC 获取 `userData` 路径，JSON 文件存储配置
  - `main.js` → 新增 IPC handler `get-userdata-path`
  - `scripts/config.js` → 完全重写，零外部依赖
  - `package.json` → 移除 `electron-store` 依赖（减少 20 个包）

### Bug 2：renderer.js 中 require 相对路径解析错误
- **现象**：`Cannot find module './api.js'`
- **原因**：Electron 通过 `<script src>` 加载的脚本，`require()` 相对路径从 HTML 文件目录（项目根）解析，而非脚本文件所在目录
- **修复**：`renderer.js` 中 require 路径改为 `./scripts/api.js` 等（从项目根开始的路径）
